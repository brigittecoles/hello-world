The Sovereign AI Standard · Visual System

A public standard carries a struck mark — proof it was assayed, graded and entered on a register. This is that instrument, set as an official publication: monospaced, box-ruled, struck in text, and finished in graphite & silver. The apex retains a single champagne strike; nothing else is warm.

Silver is a tonal ramp.

§ 03 · THE MARK

A struck seal, in text.

The medallion, plotted on a character grid: a milled rim, an engraved inner ring, and the three ascending bars with an apex star. It holds as a coin at 12px and reduces to a single glyph — ◈.

§ 04 · CERTIFICATION MARKS

The hallmark, three finenesses.

What a certified product displays. The device carries the metal; the fineness code is borrowed from silver assay. Restrained by design — the apex is the only warm strike.

[░░]  SOVEREIGN AI

[✦█]  SOVEREIGN AI
Certified :: LVL 03 · Sovereign
Platinum / Assay 950

The apex mark [✦] is the only warm strike in the system. Everything below it stays cool — that restraint is what makes LVL 03 read as rare.

§ 06 · HANDOFF

What ships this.

A render layer over the same silver tokens: commit the type stack to mono, add the box-frame primitive, and generate the ASCII asset set. Palette tokens carry over from the silver system — deepened for the graphite-only finish.

hallmark-ascii.css
/* 1 — type: commit to mono */
:root{ --mono:'IBM Plex Mono',ui-monospace,monospace; }
body{ font-family:var(--mono); }

/* 2 — section frame (legend on the rule) */
section.box{ border:1px solid var(--edge); position:relative }
section.box > .t{ position:absolute; top:0; left:22px;
  transform:translateY(-50%); background:var(--bg); padding:0 12px }

/* 3 — metal = character ramp (no CSS gradients required) */
--ramp: " .:-=+*#%@"  |  " ░▒▓█";

/* palette — graphite & silver, single finish */
--bg:#08090B; --ink:#D4DAE2; --edge:#3C434D; --champ:#CBAE76;
